# Legacy Swift prototype

This directory is retained as historical reference only. ShotEye is shipped and developed from the Tauri application in `../tauri-app/`.

The root build and run scripts intentionally do not invoke this prototype, so a local package operation cannot create a second screenshot app with a different implementation.

If historical behavior must be inspected, run `swift run ShotserLegacy` from this directory. Do not use it for ShotEye development or release packaging.
